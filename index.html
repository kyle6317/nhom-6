Hướng dẫn cách đưa website lên internet với Github Pages

Bước 1: Tạo tài khoản Github

Truy cập https://github.com/signup để tạo tài khoản

Bước 2: Tạo website

Bước 2.1: Tạo Repo

Truy cập https://github.com/new để tạo Repo, đặt tên Repo, ví dụ nhom-6 Bật Add README Nhấn Create repository

Bước 2.2: Tạo website

Nhấn Nút Add file --> Create new file Đặt tên file .html và soạn thảo mã nguồn website Nhấn nút Commit changes để Lưu

Bước 3: Đưa website lên internet

Tại trang chủ dự án, chọn Settings --> Pages, tại Branch đổi từ None thành Main, nhấn *Save để lưu lại Chờ một chút để Github build website và truy cập username.github.io/repo/ten-file.hmtl Trong đó:

  • username: là username Github của bạn
  • repo: là tên Repo lúc bạn tạo
  • ten-file.html là file html bạn tạo
